# COVID-19 Functional Data Analysis

Project developed during my Master's degree in Applied Mathematics and Data Science at the University of Rennes.

## Objective

The objective of this project is to analyze the temporal dynamics of the COVID-19 pandemic using **functional data analysis** techniques.

Daily time series of COVID-19 cases are transformed into functional representations to study trends and variability across countries.

## Methods

The following statistical techniques were used:

- B-splines basis functions
- Fourier basis functions
- Penalized least squares smoothing
- Functional Principal Component Analysis (FPCA)

## Dataset

The dataset contains daily COVID-19 statistics collected for multiple countries, including:

- cumulative_total_cases
- daily_new_cases
- active_cases
- cumulative_total_deaths
- daily_new_deaths
